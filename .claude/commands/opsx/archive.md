---
name: "OPSX: Archive"
description: "Archive a completed, selected OpenSpec increment when the user requests close-out. Not an automatic consequence of any code change."
---

Read and follow [the shared openspec-archive-change skill](../../skills/openspec-archive-change/SKILL.md).
Apply it to `$ARGUMENTS` within the user's selected increment and authorization.
The repository's `AGENTS.md` governs scope and validation; this command introduces
no separate workflow or automatic OpenSpec requirement.
