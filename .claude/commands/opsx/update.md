---
name: "OPSX: Update"
description: "Update artifacts of an existing selected OpenSpec increment to reflect agreed decisions or implemented changes. Does not create a standing documentation workflow."
---

Read and follow [the shared openspec-update-change skill](../../skills/openspec-update-change/SKILL.md).
Apply it to `$ARGUMENTS` within the user's selected increment and authorization.
The repository's `AGENTS.md` governs scope and validation; this command introduces
no separate workflow or automatic OpenSpec requirement.
