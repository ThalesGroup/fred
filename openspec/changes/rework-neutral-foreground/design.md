## Context

See proposal.md - Why. Text and outline tokens map onto the same `--core-cold-grey-*` ramp regenerated by `rework-neutral-surface-scale`.

## Decisions

**Tones chosen by contrast, not by M3 defaults.** Light `on-surface-retreat` 40 gives 6.5:1 on white and 5.4:1 on `surface-container-highest`. Light `on-surface-muted` needs a step between 40 and 50 (50 is 4.48:1 on white), so tone 45 is added to the ramp with the same LCh formula. Dark `on-surface-retreat` 75 and `on-surface-muted` 60 (5.9:1 on the page; the previous 50 was 4.15:1).

**Merge `outline-retreat` into `outline-muted`.** In light they were the same value; in dark they were 30 and 20. The merged token takes dark 25 (30 read too bright in review), so the 78 former `outline-muted` usages become slightly more visible in dark while staying visible on `surface-floating` (20). Light borders get softer: `outline-variant` 70 → 80, `outline-muted` 80 → 88. `outline` stays the 3:1 non-text contrast line for hover and focus. Form controls that used `outline-retreat` (inputs, selects, tag input, switch, scrollbar thumb) move to `outline-variant` instead, so their resting border stays distinct from dividers and from their `outline` hover.

**Text usages keep their token.** `on-surface-retreat` (secondary text, icons) and `on-surface-muted` (meta, placeholders) already map to roles; only their tones change. Undefined references are repointed to the defined token with the same role.

**Deletion over aliasing.** Dead aliases and unused state tokens are removed instead of kept "for compatibility": nothing references them in this repo, and the package migration table names their replacements.

## Risks / Trade-offs

- [`--outline-retreat` removal breaks `@fred-oss/design-tokens` consumers that use it] → README migration table maps it to `--outline-muted`; the package is still `0.x` alpha.
- [`on-surface-muted` light 45 is 3.8:1 on filled fields] → acceptable for placeholders; body text on fields uses `on-surface`.
