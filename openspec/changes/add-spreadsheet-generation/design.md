## Goals / Non-Goals

**Goals:** a correct, nicely formatted `.xlsx` from one tool call; every malformed input rejected with a message the model can act on; same behaviour on ReAct, Deep and Graph; no new platform surface.

**Non-Goals:** charts, conditional formatting, merged cells, multiple tables per sheet, editing existing workbooks, templates, free-form formulas, preview, server-side export of query results.

## Decisions

Owner decisions (2026-10-21) closed the draft's open questions: new small package (Q1), download chip only (Q2), per-column currency symbol (Q3), admin-gated like other capabilities (Q4), templates in a later slice (Q5).

### D1. New capability in its own package

- `writable_document` is a co-edited Markdown document with an owned table, an editor side panel and a router export. A spreadsheet has none of that lifecycle.
- `fred-capability-documents` holds readers over Knowledge Flow ports; writing files is a different direction and different ports.
- The tabular MCP server (Knowledge Flow) is read-only SQL over ingested datasets.
- The PPT package is mid-rework and couples python-pptx and LibreOffice; a separate package `fred-capability-spreadsheet` shares nothing with it.

### D2. Tool schema (Mistral-friendly)

```
create_spreadsheet(
  file_name: str,                       # without extension; sanitised
  sheets: list[Sheet],                  # 1..10
)
Sheet  = { name: str, columns: list[Column], rows: list[list[str | int | float | bool | None]] }
Column = { header: str,
           type: "text" | "number" | "integer" | "percent" | "currency" | "date" = "text",
           currency: "EUR" | "USD" | "GBP" | "CHF" | "JPY" | "CNY" | "CAD" | "AUD" | None = None,
           width: int | None = None,      # characters; computed when absent
           total: "sum" | "average" | "min" | "max" | "count" | None = None }
```

Scalar cells only: dates are ISO strings (`YYYY-MM-DD`); percents accept `0.15` or `"15%"`; numeric strings accept a decimal comma and a currency sign. Enum values are case-insensitive. `currency` applies to `currency` columns only; without it the column uses `#,##0.00` with no symbol. Unknown keys are ignored.

### D3. Generation

openpyxl in a worker thread (`asyncio.to_thread`), validation included, so the event loop never blocks. Header: bold, neutral fill, bottom border; `freeze_panes="A2"`; `auto_filter` over header and data. Number formats: integer `#,##0`, number `#,##0.00`, percent `0%` (up to two decimals when the values need them), currency `#,##0.00` with the symbol (`#,##0.00 "€"`, `"$"#,##0.00`, `"¥"#,##0`, ...), date `yyyy-mm-dd`. Widths: declared (clamped 4..100), else `min(max(len(header), longest cell) + 2, 60)`. Totals row: bold, label "Total" in the first text column without a total, `=SUM(B2:B{n})` etc. in the flagged columns (`COUNTA` for a text column's count), with the column's number format. Workbook `creator="Fred"`. Byte-identical output is not a goal: openpyxl stamps zip and core-property times; tests read the workbook back instead.

### D4. Validation and limits

Rejected with an `is_error` result naming sheet / row / column: sheet name empty, longer than 31, containing `[]:*?/\`, starting or ending with `'`, or duplicated (case-insensitive); zero columns; a row longer or shorter than the columns; a value not convertible to its column type; a `sum`/`average`/`min`/`max` total on a text or date column. Limits: 10 sheets, 50 columns, 5 000 rows per sheet, 50 000 cells in total, 2 000 characters per cell, 10 MB output. Rows are never truncated silently.

### D5. Formula-injection guard

Only the totals row holds formulas, generated by code. Any text cell starting with `=`, `+`, `-`, `@`, tab or carriage return is written as a literal string with the quote prefix, so data from documents or users cannot run as a formula.

### D6. Delivery

Path `spreadsheets/<session_id>/<file_name>-<short uuid>.xlsx` through `workspace_fs.write(..., content_type="application/vnd.openxmlformats-officedocument.spreadsheetml.sheet")`. The tool returns the download `LinkPart` and a text result telling the model a download button is shown, so it does not write a link itself (PPT Filler wording). Missing `workspace_fs` or a write failure → `is_error` result, logged.

### D7. Model steering without middleware

The tool description carries the steering ("when the user asks for an Excel file, spreadsheet, .xlsx or a table to download, call this tool; never paste a Markdown table instead"). No middleware, so Graph stays supported. If the live check shows the default model ignoring the tool, the usage block comes from #2708, not from a ReAct-only middleware.

## Risks / Trade-offs

- Large tables cost output tokens: rows pass through the model. Mitigation: limits and Help Center wording; the server-side export of query results is a separate issue.
- openpyxl does not compute cached formula values: Excel and LibreOffice recompute on open; a reader that only reads cached values (pandas without recalculation) sees empty totals. Acceptable for a download.
- A new dependency in the fred-agents image (openpyxl + et-xmlfile, pure Python).
- Generation runs on the default thread pool without a dedicated bound; the 50 000-cell limit keeps one call to well under a second.
