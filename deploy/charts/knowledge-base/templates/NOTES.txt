The Knowledge Base pod `{{ .Values.configuration.app.runtime_id }}` is deployed in namespace {{ .Release.Namespace }}.

The `publish` Job declares it to Fred's Control Plane after each install, upgrade
and rollback{{ if not .Values.publish.enabled }} (off in this release: publish.enabled is false){{ end }}.
The Control Plane accepts it only from a registered client: add this entry to the
Fred chart's values (its own values file is fine) and upgrade Fred:

    registrations:
      knowledgeBasePublishers:
        {{ .Values.configuration.security.m2m.client_id }}:
          prefix: {{ .Values.configuration.knowledge_base.prefix }}

A platform admin then enables it for teams in Fred's admin.

Worker (opens no inbound port; it receives runs through Temporal):
  kubectl -n {{ .Release.Namespace }} logs deployment/{{ include "knowledge-base.fullname" . }}
{{- if .Values.publish.enabled }}

Declaration:
  kubectl -n {{ .Release.Namespace }} logs job/{{ include "knowledge-base.fullname" . }}-publish
{{- end }}
