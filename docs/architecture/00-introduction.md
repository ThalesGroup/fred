# 0. Introduction

Fred is more than an agentic SDK or toolkit. It is a complete cloud native platform designed around a simple yet powerful security model that lets you assemble users, data (referred to as knowledge), agents into poweful domain applications. 

Fred can be easily understood as follows. If you install it you immediately benefit from a state-of-the-art multi tenant software that provides you with a natural way to organise your data and users into isolated organizations, teams and projects. 

That is howver only a startying point, Fred allows you to invent powerful domain applications by letting you develop various components specific to your use cases:

* Agents: fred SDK lets you build custom agents, automatically packaged for you as "agentic pods". An agentic pods is an application that provides one or several custom agents automatically and safely registered onto your running fred instance. 
* Knowledge Bases: data and document management is the heart of an agentic application. The fred Knowledge Base SDK lets you develop custom connectors to fetch data in your own ways and possibly process it the way you need. In turn that data is then made available to agents trough capabilities.
* Full fledged application : this last SDK pieces lets you design Fred UI extension and package any third party service you need to devlop custom applications beyond chats. The real value of fred in this space is that you can combine existing UI and service delivered from the native Fred components with your own and invent powerful custom application.
