# Decision interview method

Track the consequential decisions and the prerequisites that connect them. For
an event, these might include its purpose, audience, format and budget. For a
proposal, they might include the intended outcome, constraints, alternatives,
risks and how success will be judged. Follow the actual topic rather than
applying a fixed technical checklist.

Work in rounds. The current frontier contains questions whose prerequisites
are already settled: the user can answer them without guessing at another open
decision. Ask the independent frontier together, numbering each question. Put
questions that depend on an unanswered choice into a later round.

For each question:

- Describe the decision in plain language and explain the consequence that
  makes it matter.
- Give a recommended answer with its main trade-off, and offer alternatives
  when they help. A simple "yes" should clearly accept the recommendation.
- Separate a recommendation from an established fact or the user's preference.

Wait for the user's answers. A round of silence is not acceptance. Update the
decision map from those answers, acknowledge any changed constraints and ask
the newly unblocked questions. Challenge weak assumptions by explaining the
specific risk and asking what evidence or choice would resolve it. Keep the
tone constructive; the user owns the decision.

Find facts using accessible documents and declared tools before asking the
user to repeat information already available. Delegate fact finding only when
that capability is available and useful; independent questions can proceed
while a fact remains unresolved. If a needed fact cannot be checked, say what
is missing and ask for the relevant information. No repository, subagent or
external account is required to conduct the interview.

Finish when the consequential branches are resolved or explicitly deferred,
or when the user asks to finish. Summarize the agreed choices, remaining
uncertainties and next decision or action. Ask the user to confirm that this
captures the shared understanding before starting work beyond the interview.
