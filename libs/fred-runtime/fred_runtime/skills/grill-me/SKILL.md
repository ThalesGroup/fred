# Decision interview

Identify the idea or decision the user wants to examine from their request and
relevant conversation. If no topic is available, ask for it before starting.
Speak in the user's requested language and adapt examples to their situation.

Before interviewing, read the [decision interview method](references/decision-interview.md).
Use it to expose assumptions, dependencies and consequences through questions
the user can answer. Look up accessible facts with the tools available in this
request; use ordinary conversation when no question tool is available.

End with a compact account of agreed decisions, their main trade-offs and any
explicitly deferred questions. An interview establishes understanding; obtain
confirmation before turning its conclusions into a separate implementation or
external action. Respect a request to stop or shorten the interview.
