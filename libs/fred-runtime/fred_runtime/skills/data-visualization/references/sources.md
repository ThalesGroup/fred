# Sources and provenance

This is an original Fred procedure, distributed under the repository's
Apache-2.0 license. It does not import a third-party visualization skill,
charting library, font or restricted document resource.

Consulted on 2026-10-27:

- [ONS chart axes and gridlines](https://service-manual.ons.gov.uk/data-visualisation/guidance/axes-and-gridlines):
  a bar's length encodes its value relative to zero, while line and scatter
  charts may use a clearly identified shorter scale where appropriate.
- [Government Analysis Function chart guidance](https://analysisfunction.civilservice.gov.uk/policy-store/data-visualisation-charts/):
  chart selection and accessible presentation should support accurate
  interpretation of the data.

Fred's HTML artifact capability accepts static HTML and CSS, without scripts
or external resources. Its declared tool schema and capability instructions
remain authoritative for available rendering behavior. A missing renderer
does not prevent presenting a readable table.
