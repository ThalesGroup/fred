# Verify an answer

1. Identify the answer or draft to check in the request or relevant conversation.
   If there are several plausible targets, ask which one. If none is available,
   ask for the answer before claiming to have verified it.
2. Identify its consequential factual claims, figures, citations and conclusions.
   Compare them with sources actually readable through available tools or context.
   Check dates, units, calculations and whether a citation supports the exact claim.
3. Classify material claims as supported, contradicted or unverified. Distinguish
   missing evidence from evidence of falsehood. For numerical claims, show the
   corrected calculation when the available inputs make it checkable.
4. Provide the corrected answer or the requested review format. Explain material
   corrections and remaining uncertainty with source attribution. If sources are
   unavailable, limit the review to consistency and checkable calculations and
   state that external factual verification remains incomplete.
