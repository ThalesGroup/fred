# Compte rendu

1. Lire les notes fournies. Si elles ne sont pas présentes, les demander. Si elles
   désignent un document, le lire avec un outil disponible ; si aucun outil ne
   permet cette lecture, expliquer ce blocage et demander les notes.
2. Lire le modèle avec :

       read_skill_file("compte-rendu", "references/modele-compte-rendu.md")

3. Rédiger le compte rendu selon ce modèle, dans la langue demandée. Distinguer
   les faits, décisions et actions ; ne pas transformer une proposition en décision.
4. Pour chaque action, reprendre seulement le responsable et l'échéance indiqués
   dans les notes. Écrire « Non précisé » pour toute donnée absente. Ne pas
   déduire une date, une personne ou un résultat.
5. Vérifier que chaque décision et action s'appuie sur les notes, puis fournir
   le compte rendu. Si une étape reste bloquée, préciser ce qu'il manque.
