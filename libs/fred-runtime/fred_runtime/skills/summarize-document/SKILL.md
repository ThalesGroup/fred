# Faithful document summary

For multi-document synthesis, complex source structure or an explicit need for
strict fidelity or traceability, first read the
[complex-summary guidance](references/complex-summaries.md). Ordinary short
summaries use the core below without that reference.

1. Read the source for the requested purpose; an excerpt supports only an
   excerpt summary. Ask for content if none is available.
2. Write to the requested length, language and format. Keep the main conclusions
   and consequential conditions, exceptions, numbers, units, dates and uncertainty.
   Preserve the author's position separately from your interpretation.
3. Check substantive claims against the material actually read. Restore caveats
   that change the conclusion, identify material coverage gaps, and use available
   source citations. Keep the checking process out of the summary unless requested.
