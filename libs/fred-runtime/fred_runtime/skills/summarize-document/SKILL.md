# Faithful document summary

1. Identify the document and the user's purpose from the request or conversation.
   Read it with an available tool when necessary. If only an excerpt is available,
   scope the summary to that excerpt; if no content can be read, ask for it.
2. Select the main conclusions and the details needed for the stated purpose.
   Preserve conditions, exceptions, dates, units and uncertainty that affect the
   meaning. Distinguish the author's conclusions from your own interpretation.
3. Draft a concise summary in the requested language and format. For several
   documents, retain source attribution and material disagreements rather than
   merging them into an artificial consensus.
4. Check each substantive statement against the available content. Restore any
   omitted caveat that would change the conclusion. Identify unread sections or
   missing context that limits the summary. Use actual source citations when
   available, without claiming coverage of material that was not read.
