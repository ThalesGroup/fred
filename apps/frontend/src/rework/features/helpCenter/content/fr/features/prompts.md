# Les prompts

Un **prompt** est un texte réutilisable : une question type, une consigne, un
cadre de réponse. La page **Prompts** de votre équipe rassemble cette
bibliothèque partagée.

> Créer et organiser les prompts de l'équipe demande le rôle **Éditeur**. Tout
> membre peut les consulter et les utiliser.

## Catégories

Les prompts se rangent dans des **catégories** propres à l'équipe, que vous
créez, renommez et réorganisez. Une nouvelle équipe démarre avec quelques
catégories et prompts d'exemple, pour ne pas partir d'une page blanche.

Supprimer une catégorie qui contient encore des prompts est bloqué : videz-la ou
reclassez-les d'abord.

## Créer, consulter, réutiliser

Un prompt porte un titre et un contenu. Sa fiche permet de le consulter et de le
copier. Un compteur indique combien de fois il a servi : un repère utile pour
distinguer les prompts réellement utilisés des autres.

Un prompt sert à deux endroits :

- **dans une conversation**, inséré pour ne pas réécrire une demande
  récurrente ;
- **dans la configuration d'un agent**, attaché pour orienter durablement son
  comportement (voir [Les agents](/help/fr/features/agents)).

> Un prompt d'équipe bien rédigé évite que chacun réinvente la même
> formulation. Des catégories explicites permettent à un nouvel arrivant de
> comprendre l'organisation sans assistance.
