# Fonctionnalités

Cette section décrit chaque fonctionnalité en détail. Choisissez un thème :

  assistants IA.
- [La bibliothèque de prompts](/help/fr/features/prompts) — catégories,

- [Les ressources documentaires](/help/fr/features/resources) — déposer,
