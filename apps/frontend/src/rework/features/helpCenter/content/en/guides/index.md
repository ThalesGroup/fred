# Guides

The other sections describe the tools; these guides chain the steps to reach a
result.

| I want to…                              | Guide                                                             |
| --------------------------------------- | ----------------------------------------------------------------- |
| An agent that answers from my documents | [Build a document assistant](/help/en/guides/build-rag-assistant) |
| To know whether an agent answers well   | [Evaluate an agent](/help/en/guides/evaluate-agents)              |

> Producing a document, filling a deck, questioning a spreadsheet: those are
> **functions** to enable on the agent, described in
> [Agents](/help/en/features/agents). There is no particular walkthrough —
> enable the function, then ask.
