# Résumé fidèle de document

Pour une synthèse de plusieurs documents, une source à la structure complexe ou
un besoin explicite de fidélité stricte ou de traçabilité, lisez d'abord les
[consignes pour les résumés complexes](references/complex-summaries.md). Les
résumés courts ordinaires utilisent le socle ci-dessous sans cette référence.

1. Lisez la source en fonction de l'objectif demandé ; un extrait ne permet que
   le résumé de cet extrait. Demandez le contenu s'il n'est pas disponible.
2. Rédigez à la longueur, dans la langue et au format demandés. Conservez les
   conclusions principales ainsi que les conditions, exceptions, chiffres,
   unités, dates et incertitudes qui comptent. Distinguez la position de l'auteur
   de votre interprétation.
3. Vérifiez les affirmations importantes par rapport au contenu réellement lu.
   Rétablissez les réserves qui changent la conclusion, signalez les lacunes de
   couverture importantes et utilisez les citations de sources disponibles.
   Laissez le processus de vérification hors du résumé, sauf demande contraire.
